    Citing BacFlux¶

    Antonielli, L. (2026). BacFlux: a unified Snakemake workflow for bacterial whole-genome sequencing. Zenodo. https://doi.org/10.5281/zenodo.11143917

    That DOI is the concept DOI — it always resolves to the newest release. Every tagged release also gets its own version DOI on Zenodo. Cite the version DOI when the exact code matters, which for a methods section it usually does.

    The first Zenodo record, v1.1.5 (2024, https://doi.org/10.5281/zenodo.11143918), also credits D. K. Großkinsky, H. Koch, F. Trognitz, A. Sanchez Mejia and M. Nagel; cite it for work done with that version.

    Machine-readable metadata is in CITATION.cff; GitHub reads that file to build a citation for you.

    The retired sibling workflows keep their DOIs

    v2.0.0 folds BacFluxL and BacFluxL+ into this repository. Their Zenodo records stay valid, so an analysis already published with one of them remains citable and reproducible — cite the record you actually ran. See Coming from v1.

    Cite the tools as well¶

    BacFlux combines established tools and reference databases with its own processing and interpretation rules. Cite the components that contributed to the reported results, as well as the workflow.

    Which references you need depends on the mode you ran and on which optional stages you switched on, so the tables below are grouped that way. The complete list, with the licensing notes attached, is in CITATIONS.md.

    Optional stages and layers¶

    Each of these is off until you turn it on, and each brings its own citations.

    Switch What runs Reference
    phage.caller: genomad geNomad 1.12.0 replaces VirSorter2 as the virus caller, and its plasmid calls are compared with Platon's 11
    baktfold.run: true Baktfold 0.3.0, which turns each of Bakta's hypothetical proteins into a string of Foldseek's 3Di structural alphabet with the ProstT5 language model, then searches them with Foldseek against SwissProt, AlphaFold Database clusters, PDB and CATH to suggest names — cite all three; if you report which database a name came from, cite that database as well (Baktfold's README lists the papers) 7, 33, 61
    traits.run: true the trait profile: every protein of up to 4,000 amino acids is turned into a string of Foldseek's 3Di structural alphabet by Baktfold's ProstT5 step, then searched with Foldseek against EcoFoldDB v2.0 — cite EcoFoldDB, Baktfold, ProstT5 and Foldseek; the papers behind each rule are in the reference column of its rules table (Trait profile) 29, 7, 33, 61
    mobilome.run: true AMRFinderPlus, run from the Bakta environment against the AMRFinderPlus database that ships inside bakta_db; ISEScan 1.7.3 and MacSyFinder 2.1.6, both HMMER searches; and the CONJscan models MacSyFinder runs — cite all three CONJscan papers; they are the models that run 28, 27, 65, 47, 23, 1, 19, 20
    mobilome.icescan.run: true the ICEscan model set, distributed with ICEfinder2 and itself a fork of CONJscan — so cite the ICEberg paper and the three CONJscan papers 62, 1, 19, 20
    mobilome.tncentral.url or .dir TnCentral, to name curated transposons and integrons 56
    mobilome.iceberg.urls or .dir ICEberg 3.0 sequences, to name the ICE and IME candidates 62
    mobilome.isosdb.fasta_url + family_map_url, or .dir ISOSDB read mapping with BBMap, for IS copy number 36, 9

    The mobility tiers are organised around EFSA's distinction between intrinsic and acquired resistance genes (refs 24, 25). They provide genomic-context evidence; they do not establish that a gene is intrinsic and do not demonstrate transfer. Antimicrobial resistance lists the two further EFSA documents — the 2024 WGS statement behind the 80%/70% thresholds, and the Bacillus catalogue — and the intrinsic/acquired methods page sets out what the evidence supports.

    ISfinder reaches a run only through Bakta's database

    Bakta's database integrates annotations from the ISfinder database, so cite ISfinder when you report Bakta's insertion-sequence annotations. BacFlux itself downloads nothing from ISfinder: TnCentral publishes further endpoints whose content carries ISfinder's terms, and those are deliberately not wired into config.yaml. If you point mobilome.tncentral.url at one of them yourself, cite ISfinder as well:

    Siguier, P., Perochon, J., Lestrade, L., Mahillon, J., & Chandler, M. (2006). ISfinder: the reference centre for bacterial insertion sequences. Nucleic Acids Research, 34(Database issue), D32–D36. https://doi.org/10.1093/nar/gkj014

    Terms for every optional layer are listed on Licensing; what each layer adds is on Optional layers.

    Design influence¶

    Work that shaped BacFlux without contributing code to it; the distinction is spelled out on Licensing.

    • EBI Mobilome Annotation Pipeline (Apache-2.0). https://github.com/EBI-Metagenomics/mobilome-annotation-pipeline — from which BacFlux adopted decisions rather than code: that ICEscan exists and is worth running, Sequence Ontology terms for element types (BacFlux's mge_type column), the contig_id|mge_type-start:end element ID format, the discard-with-reason file and the 0.9 CDS-coverage rule. Their 500 bp minimum element size is deliberately not applied to IS calls, because a short call is usually a partial IS cut by a contig break. The two pipelines answer different questions: theirs goes deep on the mobilome of metagenomes and MAGs, BacFlux covers reads through to AMR mobility for single isolates.
    • ICEfinder2, whose variable-length repeat search — rather than a fixed-length probe — is why BacFlux's att-site search works the way it does. Established by reading it, then implemented independently.

    • NCBI FCS-adaptor (https://github.com/ncbi/fcs), whose rule for a contig end the adapter screen follows: an adapter hit within 100 bp of the end of a linear contig counts as being at that end. BacFlux runs no FCS code; run FCS-adaptor itself before a GenBank submission.

    • Puterová, J. & Martínek, T. (2021) digIS: towards detecting distant and putative novel insertion sequence elements in prokaryotic genomes. BMC Bioinformatics 22:258. https://doi.org/10.1186/s12859-021-04177-6 — benchmarked here for the IS false-discovery figures quoted on the mobilome pages, not run by BacFlux.
